# Screen capture

Press `Super+Shift+S`. The desktop freezes and a toolbar appears; pick a mode,
then **Capture**/**Record** (or Enter). Esc closes it.

| Key | Mode |
| --- | --- |
| 1 | Screenshot all screens |
| 2 | Screenshot a window |
| 3 | Screenshot a region |
| 4 | Record a screen |
| 5 | Record a window |
| 6 | Record a region |

- **Window:** hover a window, click to lock it.
- **Region:** drag, then move or resize with the handles.
- While recording, the bar shows elapsed time and **Stop**.

Captures are saved by the [`screen-capture-*` commands](../../../screen-capture/README.md),
which also work on their own.

## Edit a screenshot

Press **Edit** on the screenshot notification. Drag on the image to crop, or
to draw a rectangle, an ellipse or a pen line; click to type text, and press
Enter to place it. Pick the color and line width in the toolbar.

| Key | Action |
| --- | --- |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z, Ctrl+Y | Redo |
| Ctrl+S | Save |
| Esc | Cancel the text, then close without saving |

**Save** overwrites the screenshot and copies it to the clipboard.
